# MakeYourOwnRecipe V2

A validation MVP for the question:

> What should I cook tonight?

## What is included

- Next.js + TypeScript
- Warm editorial consumer-food UI
- Time, situation and kitchen-ingredient inputs
- Deterministic recommendation engine
- 25 Indian dinner recipes
- Exactly 3 recommendations
- "Show me 3 more" without immediate repeats
- Cooking state
- Loved / Good / Never again feedback
- Responsive mobile-first layout
- No login, database, AI API or other infrastructure

## Run locally

Requirements:
- Node.js 20+

```bash
npm install
npm run dev
```

Open:

http://localhost:3000

## Build

```bash
npm run build
npm run start
```

## Product intent

This is deliberately small. The goal is to validate whether people value fast dinner decision support before adding accounts, persistence, AI, meal planning, grocery lists, or payments.
